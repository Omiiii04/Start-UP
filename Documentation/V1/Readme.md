
# Technology Services & AI Engineering Consultancy

## Overview

We are a process-driven technology services consultancy based in **Pune, Maharashtra**. Our core operations focus on providing high-quality software engineering, cloud infrastructure deployment, artificial intelligence and machine learning solutions, MLOps, and technical research mentorship to student innovators, academic researchers, and small-to-medium enterprises (SMEs).

Our engineering philosophy prioritizes **architecture-first development, legal integrity, and standardized delivery workflows**.

---

# Core Mission & Compliance Principles

## Mission

To bridge the gap between academic research, early-stage product prototyping, and enterprise-grade technology execution by offering structured, affordable, and highly reliable software engineering services.

---

## UGC & Academic Integrity Compliance

In strict adherence to the **University Grants Commission (Promotion of Academic Integrity and Prevention of Plagiarism in Higher Educational Institutions) Regulations, 2018**, this entity does **not** provide:

- Ghostwriting
- Academic proxy services
- Direct execution of graded student coursework

Our engagements with students and researchers are strictly limited to:

- Technical mentorship
- Code reviews
- Debugging assistance
- Infrastructure engineering (MLOps setup, dataset preprocessing, cloud deployment)
- Custom software development delivered as:
  - Open-source Proof-of-Concept (PoC) software
  - Client-owned enterprise software under standard Intellectual Property (IP) agreements

# Onboarding & Development Setup

## Prerequisites

- Git 2.x+
- Node.js v20.x LTS
- Python 3.11+
- Docker Desktop / Containerd
- PostgreSQL 16+

---

## Local Environment Setup

### 1. Clone the Repository

```bash
git clone https://github.com/your-org/platform-core.git
cd platform-core
```

### 2. Copy Environment Variables

```bash
cp .env.example .env.local
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Verify Code Quality

```bash
npm run lint
```
